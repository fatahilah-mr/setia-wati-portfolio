This repository contains the source code for the personal portfolio of **Setia Wati** (Kwettiau). Designed and built by **Fatahilah Miftahul Rahman**, it is an aesthetic, interactive single-page application built with **React** and **Vite**, showcasing her journey in the IT world, hobbies, and personal favorites.

> [!TIP]
> Explore the live site to see the smooth animations and interactive elements in action, including 3D hover tilt effects and a custom favorite songs widget.

## Features

- ⚡ **Lightning Fast Build** - Powered by Vite for instant server start and rapid HMR.
- 🎨 **Aesthetic UI/UX** - Beautiful pink pastel theme, glassmorphism elements, and fully responsive design.
- 🪄 **Smooth Animations** - Utilizes `motion` for fluid page transitions, scroll spy, and micro-interactions.
- 🛠️ **Modern Tech Stack** - Built with React 19, TypeScript, and Tailwind CSS.
- 🎵 **Interactive Playlist** - Features a custom music widget displaying favorite tracks.
- 📬 **Direct Contact** - Includes an integrated email form modal to get in touch seamlessly.

## Architecture

The project is structured following standard React and Vite conventions:

- `src/` - Contains the main application source code.
  - `src/App.tsx` - The main application component containing the portfolio's sections.
  - `src/components/` - Reusable UI components like `LazyImage`.
  - `src/data/` - Static data files (e.g., playlist data).
  - `src/assets/` - Static assets including images and icons.
- `public/` - Public assets served directly, including SEO files like `robots.txt` and `sitemap.xml`.

## Getting Started

To run this project locally, you need [Node.js](https://nodejs.org/) installed on your machine.

**1. Clone the repository:**
```bash
git clone <your-repo-url>
cd web-setia-wati
```

**2. Install dependencies:**
```bash
npm install
```

**3. Start the development server:**
```bash
npm run dev
```

The site will be available at `http://localhost:3000` (or `http://0.0.0.0:3000` as configured).

**4. Build for production:**
```bash
npm run build
```
The compiled static files will be generated in the `dist/` directory, ready to be deployed.
